# Landing (/ and /en/) — surface brief

- **Audience**: recruiters, engineering hiring managers, collaborators, and clients.
- **Thesis**: identity and an immediately usable terminal invite exploration; BazPOS provides the first substantive project proof.
- **World**: Lavender Working Directory; light lavender surfaces, dark plum typography, purple actions, Rethink Sans for reading and IBM Plex Mono for genuine terminal commands.
- **First viewport**: oversized name spanning the page, then introduction and project/contact actions beside the working terminal. Stack at 751px and below without autofocus.
- **Story**: introduction + interactive terminal → BazPOS screenshot, workflow and architecture → other projects → tools → linked engineering examples → direct contact.
- **Terminal**: shared with `/terminal/` and `/en/terminal/`; local scrolling, clickable commands, help, project details, contact, section navigation, session history, and Tab completion. No simulated shell execution or telemetry. No repeated decorative readiness markers.
- **BazPOS**: desktop sticky authentic report screenshot beside three reading chapters; full-width report screenshot and flowing text on mobile and with reduced motion. Recording and live demo remain on the project presentation.
- **Evidence**: project source links and shared engineering examples for layer responsibilities, isolated Docker demo deployment with daily resets, and static bilingual progressive enhancement. No invented metrics.
- **Accessibility**: normal links without JavaScript; terminal fallback explanation; one main landmark; focusable output region, polite output log, explicit input label, visible focus, mobile wrapping, reduced motion, and no automatic page scrolling from informational commands.
- **Validation**: Astro checks/build, command resolver tests, browser checks of localized commands, history/completion, safe text, section navigation, and responsive layout. New screenshots are validation captures, not generated product assets.

- **Motion**: CSS-only shared title/terminal entrances, separate hero-exit timeline, a named desktop BazPOS scene timeline, group reveals and immediate keyboard focus. No animation libraries or scroll handlers; reduced motion removes spatial effects and sticky staging.

- **Themes**: shared light lavender and dark plum palettes. A localized sun/moon control follows the system until a manual choice is saved; the choice persists across pages and languages.
